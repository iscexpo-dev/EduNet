# EduNet Web Implementation Plan

1. Establish a shared responsive public shell while preserving the existing root providers and theme initialization.
2. Replace the starter home page with a bilingual, accessible education platform landing page.
3. Add public directory, institution, help, and contact surfaces using real route links and explicit unavailable states.
4. Continue hardening role portals around existing API contracts, with server authorization remaining authoritative.
5. Validate with focused typecheck, lint, browser smoke checks, and a final implementation report.

No framework, auth system, or backend service is migrated as part of this plan.
